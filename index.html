基本設定

選擇要編輯的 Mutator 實例（同一伺服器可疊加多組 AdvancedCheckpoint 設定），並可為這份設定加上標題註解。編輯完成後，切換到左側「輸出 .ini」分頁即可取得完整設定檔文字。

Escort Mission 相容開關

VIP 護送模式使用自成一套的據點邏輯；若你的模式是 VIP 護送任務，需開啟此項，AISoldier Classes / Bot Soldiers Obj 才會正常套用。

使用流程

1. 在「AI 兵種」分頁登錄自訂兵種路徑（或套用預設兵種包）。
2. 在「據點兵力配置」分頁，用字母轉盤選擇要設定的據點，指定該點會出現哪些兵種、套用哪組移除規則。
3. 視需求開啟反擊機制 / 軍需品 / 門陷阱 / 威脅火力 / HQ 火力支援。
4. 到「輸出 .ini」分頁複製或下載成品，貼進伺服器的 Mutators.ini。

AI 兵種設定（AISoldier Classes）

登錄自訂兵種類別路徑（索引由 63 開始自動編號）、設定兵種移除規則組，以及戰情提示訊息（EnemyForceTips）。這些內容會被「據點兵力配置」與「反擊機制」分頁引用。

自訂兵種類別（CustomAISoldierClasses）

索引由 63 起依序自動編號。可用下方選單快速套用本模組內建的專屬兵種包（NightStalker、Warlord、SkullRogue…），或手動貼上其他模組的完整類別路徑。

目前索引範圍： （無）

兵種移除規則組（ClassesToRemoveSet 0–5）

依「索引」比對移除，從下拉選單挑選上方登錄的自訂兵種，或官方內建的 0–62 兵種類別。

兵種移除規則組（RemoveClassesContaining 0–5）

依「關鍵字」比對兵種名稱進行移除，較彈性，多數情況已足夠使用（例如 "Rifleman"、"Marksman"）。

戰情提示（EnemyForceTips）

依序輸入提示文字，之後在「據點兵力配置」用 EFT 索引指定各據點顯示第幾則。支援 Rich Text 標籤，例如 <BoldCyan>…</>。

據點兵力配置（Bot Soldiers Obj）

用下方轉盤選擇 Default（預設）、CounterAttack（反擊時套用）或 A–Z 各據點，分別指定出現的兵種、套用的移除規則組，以及 EFT / RFS 索引。

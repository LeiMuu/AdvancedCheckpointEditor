# Advanced Checkpoint Editor

**An advanced web-based editor for creating and customizing Checkpoint scenarios in Insurgency: Sandstorm.**

---

## Overview

**Advanced Checkpoint Editor** is a browser-based tool designed to simplify the creation and customization of **Checkpoint** scenarios in *Insurgency: Sandstorm*.

It provides an interactive interface for configuring scenario-related data that would otherwise require manually editing configuration files or repeatedly testing changes in-game.

The goal is to make advanced Checkpoint customization more accessible to both experienced modders and server administrators.

---

## Features

* Create and edit Checkpoint scenario configurations
* Configure enemy and security forces
* Customize checkpoint-related settings
* Adjust scenario parameters
* Generate configuration data for use with Insurgency: Sandstorm
* Interactive editing without manually modifying raw configuration files

The editor is designed to make complex scenario configuration easier to understand, modify, and reproduce.

---

## For Mod Developers

Advanced Checkpoint Editor is intended primarily as a development and configuration tool for **Insurgency: Sandstorm modding**.

Instead of repeatedly editing configuration values by hand and testing every change in-game, the editor provides a structured interface for configuring scenarios.

This can be useful when creating:

* Custom Checkpoint scenarios
* Custom enemy compositions
* Custom security forces
* Difficulty adjustments
* Experimental gameplay configurations
* Server-specific Checkpoint experiences
* Mod-based scenario variations

---

## Workflow

A typical workflow is:

```text
Configure
   ↓
Generate
   ↓
Apply to your Mod / Server
   ↓
Test in-game
   ↓
Adjust
   ↓
Repeat
```

The editor is intended to reduce the amount of manual configuration required during this process.

---

## Web-Based & Offline

The editor runs entirely in the browser and does not require a backend service.

It is designed to be:

* Lightweight
* Portable
* Easy to share
* Easy to run locally
* Suitable for offline use

No account or server-side processing is required for the editor itself.

---

## Technology

The application is built using standard web technologies:

* HTML
* CSS
* JavaScript

The editor performs its configuration and generation logic directly in the user's browser.

---

## Compatibility

This project is developed for **Insurgency: Sandstorm** and is intended for use with its modding and Checkpoint configuration systems.

Game updates may change available configuration options or behavior. Generated configurations should therefore always be tested against the target game version.
